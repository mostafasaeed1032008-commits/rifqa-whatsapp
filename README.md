# 🕋 رِفقة CRM الذكي ومحرك واتساب 24/7 (Rifqa WhatsApp Engine)

نظام فرز معتمري الواتساب وإدارة الحجوزات اللحظية لعلامة «رِفقة» لرحلات العمرة.

---

## 🚀 التشغيل السحابي 24/7 على Render.com

1. ادخل على [Render.com](https://dashboard.render.com).
2. اضغط **New** ➔ واختر **Web Service**.
3. اربط حسابك مع مستودع GitHub هذا.
4. اضبط الإعدادات التالية:
   * **Name:** `rifqa-whatsapp-bot`
   * **Environment / Runtime:** `Node`
   * **Build Command:** `npm install`
   * **Start Command:** `node server.js`
5. اضغط **Deploy Web Service**.
6. بعد انتهاء النشر، افتح صفحة الـ CRM واضغط على زر **⚙️ السيرفر** وضع رابط Render الخاص بك، ثم امسح الباركود من هاتفك ليعمل البوت 24 ساعة في السحابة حتى لو كان جهازك مغلقاً!

---

## 💻 التشغيل المحلي على الويندوز

* اضغط مرتين على ملف `start.bat`.
* سيفتح الـ CRM في متصفحك وسيبدأ محرك الواتساب تلقائياً على المنفذ `3005`.

---

## 🗄️ الربط مع Supabase

قاعدة البيانات جاهزة ومربوطة بجدول `public.leads` لحفظ المعتمرين، الحالات، وأرباح البرامج تلقائياً.
